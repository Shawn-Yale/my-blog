## 分数规划

用途：求**分数的最值**。

问题：每个物品有两个权值 $a_i$ 和 $b_i$，选出若干个物品使得 $\dfrac{\sum a_i}{\sum b_i}$ 最大 / 最小。

等价：给出 $a_i$ 和 $b_i$，求一组 $w_i \in \{0, 1\}$，最大化或最小化$\dfrac{\sum w_i * a_i}{\sum w_i * b_i}$。

若干个物品：满足给定 **约束条件** 的物品。

**通用解法：二分答案**
- 最大化：二分一个答案 $x$，判断：
	- $\displaystyle \frac{\sum w_i * a_i}{\sum w_i * b_i} \geq x \Rightarrow \sum w_i * a_i - x \sum w_i * b_i \geq 0 \Rightarrow \sum w_i * (a_i - x * b_i) \geq 0$ 

	- 如果 和式 $\geq 0$，说明 $x$ 是可行的，否则不可行。

- 最小化：二分一个答案 $x$，判断：
	- $\displaystyle \frac{\sum w_i * a_i}{\sum w_i * b_i} \leq x \Rightarrow \sum w_i * a_i - x \sum w_i * b_i \leq 0 \Rightarrow \sum w_i * (a_i - x * b_i) \leq 0$ 

	- 如果 和式 $\leq 0$，说明 $x$ 是可行的，否则不可行。

**解题思路：**
1. 明确 $a_i, \ b_i$ 是什么吗，把 $a_i - x * b_i$ 作为新权值求和
2. 明确 **约束条件** 是什么，选择合适的算法求和

## [P10505 Dropping Test](https://www.luogu.com.cn/problem/P10505)(01分数规划模板题)

**注意四舍五入**，`l * 100 + 0.5` 或 `printf(" %.0f\n", l * 100)`

时间复杂度：$\mathcal O(nlogn * log(1e4))$

```cpp
#include <bits/stdc++.h>
using namespace std;
#define endl '\n'
#define int long long
const int N = 1e3 + 10;

int n, k;
double a[N], b[N], c[N];

bool check(double x){
    double sum = 0;
    for(int i = 1; i <= n; i++) c[i] = a[i] - x * b[i];
    sort(c + 1, c + n + 1);
    for(int i = k + 1; i <= n; i++) sum += c[i];
    return sum >= 0;
}

void solve(){
    while(cin >> n >> k, n){
        for(int i = 1; i <= n; i++) cin >> a[i];
        for(int i = 1; i <= n; i++) cin >> b[i];
        double l = 0, r = 1;
        while(r - l > 1e-4){
            double mid = (l + r) / 2;
            if(check(mid)) l = mid;
            else r = mid;
        }
        cout << (int)(l * 100 + 0.5) << endl;
    }
}

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int T = 1;
    //cin >> T;
    while(T--) solve();
    return 0;
}
```

## [P4377 [USACO18OPEN] Talent Show G](https://www.luogu.com.cn/problem/P4377)(01背包 + 分数规划)

本题多了分母至少为 $W$ 的限制，无法使用上一题的贪心算法（排序）。可以考虑 **01背包**。

**01 背包**：用来解决「每件物品只能取 $0$ 或 $1$ 次，满足重量或容量约束下，最大化价值」的问题。

二分一个答案 $x$，把 $w_i$ 作为第 i 个物品的重量，$t_i - x * w_i$ 作为第 i 个物品的价值，那么 $f[n][W]$ 就是最大化价值。
**注意：$\sum w_i$ 可能超过 $W$，直接视为 $W$ 即可。**
若 $f[n][W] \geq 0$，就继续最大化 $x$。

时间复杂度：$\mathcal O(nW * log(1e8))$

```cpp
#include <bits/stdc++.h>
using namespace std;
#define endl '\n'
#define int long long
const int N = 3e2 + 10, M = 1e3 + 10, inf = 0x3f3f3f3f;

int n, W, w[N], t[N];
double dp[M];

bool check(double x){
    for(int i = 1; i <= W; i++) dp[i] = -inf;
    for(int i = 1; i <= n; i++)
        for(int j = W; j >= 0; j--){
            int k = min(W, j + w[i]);
            dp[k] = max(dp[k], dp[j] + t[i] - x * w[i]);
        }
    return dp[W] >= 0;
}

void solve(){
    cin >> n >> W;
    for(int i = 1; i <= n; i++) cin >> w[i] >> t[i];
    double l = 0, r = 1e3;
    while(r - l > 1e-5){
        double mid = (l + r) / 2;
        if(check(mid)) l = mid;
        else r = mid;
    }
    cout << (int)(r * 1000) << endl;
}

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int T = 1;
    //cin >> T;
    while(T--) solve();
    return 0;
}
```

## [P4951 [USACO01OPEN] Earthquake](https://www.luogu.com.cn/problem/P4951)(Kruskal + 分数规划)

$\displaystyle \frac{f - \sum c_i}{\sum t_i} \geq x \ \Longrightarrow \ f - \sum c_i \geq x \sum t_i \ \Longrightarrow \ f - \sum (c_i + x * t_i) \geq 0$，其中 $i \in {选择修复的道路}$

**显然**，选择修复的道路越多，利润相对越低，因此我们要选择**尽可能少的道路**进行修复；
但同时，我们**需要保证所有牧场连通**，所以我们需要选择 $n - 1$ 条边，构建**最小生成树**。

二分一个答案 $x$，把 $c_i + x * t_i$ 作为每一条边的边权，从小到大排序，构建**最小生成树**。
如果**最小生成树的总权重** $\leq f$，则说明当前 $x$ 可行，尝试更大的 $x$；否则当前的 $x$ 不可行，尝试更小的 $x$。

时间复杂度：$\mathcal O(mlogm*(2e15))$

```cpp
#include <bits/stdc++.h>
using namespace std;
#define endl '\n'
#define int long long
const int N = 4e2 + 10, M = 1e4 + 10, inf = 0x3f3f3f3f;
int n, m, f;
struct edge{
    int u, v, c, t;
    double w;
    bool operator< (const edge &t) const{
        return w < t.w;
    }
}e[M];

int p[N];
int find(int x){
    return p[x] == x ? x : p[x] = find(p[x]);
}

bool check(double x){
    double sum = 0;
    for(int i = 1; i <= m; i++) e[i].w = e[i].c + x * e[i].t;
    sort(e + 1, e + m + 1);
    iota(p, p + n + 1, 0ll);
    for(int i = 1; i <= m; i++){
        int u = find(e[i].u), v = find(e[i].v);
        if(u != v){
            sum += e[i].w;
            p[u] = v;
        }
    }
    return f >= sum;
}

void solve(){
    cin >> n >> m >> f;
    for(int i = 1; i <= m; i++)
        cin >> e[i].u >> e[i].v >> e[i].c >> e[i].t;
    double l = 0, r = 2e9;
    while(r - l > 1e-6){
        double mid = (l + r) / 2;
        if(check(mid)) l = mid;
        else r = mid;
    }
    cout << fixed << setprecision(4) << r << endl;
}

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int T = 1;
    //cin >> T;
    while(T--) solve();
    return 0;
}
```

## [P3199 [HNOI2009] 最小圈](https://www.luogu.com.cn/problem/P3199)(SPFA + 分数规划)

每条边的边权为 $w_i$，求一个环 $C$ 使得 $\displaystyle \frac{\sum_{i \in C} w_i}{\sum_{i \in C} 1}$ 最小。

二分一个答案 $x$，把 $w_i - x$ 作为边权，那么最小环就是最小值。判断最小值是否 $< 0$，即判断是否存在负环。用 $SPFA$ 判负环即可。

这边使用 $BFS-SPFA$ 的通用做法，但是判负环（特别是全源）用 $DFS-SPFA$ 更快。可看 [A07 01分数规划——b站 董晓算法](https://www.bilibili.com/video/BV1N14y1w7us/?spm_id_from=333.1365.top_right_bar_window_history.content.click&vd_source=f0489718ccab992000c983a006bde4a5)。

时间复杂度：$\mathcal O(nm*log(2e17))$

```cpp
#include <bits/stdc++.h>
using namespace std;
#define endl '\n'
#define int long long
const int N = 3e3 + 10, M = 1.3e4 + 10, inf = 0x3f3f3f3f, INF = 1e18;

int n, m;
int h[N], e[M], ne[M], idx;
double w[M], dist[N];
int vis[N], cnt[N];

void add(int a, int b, double c){
    w[idx] = c;
    e[idx] = b;
    ne[idx] = h[a];
    h[a] = idx++;
}

bool check(double x){
    for(int i = 1; i <= n; i++)
        dist[i] = INF, vis[i] = 0, cnt[i] = 0;
    vis[0] = 1;
    queue<int> q;
    q.push(0);
    while(!q.empty()){
        int u = q.front(); q.pop();
        vis[u] = 0;
        for(int i = h[u]; ~i; i = ne[i]){
            int v = e[i];
            if(dist[v] > dist[u] + w[i] - x){
                dist[v] = dist[u] + w[i] - x;
                cnt[v] = cnt[u] + 1;
                if(cnt[v] >= n + 1) return true;
                // 注意本题用了超级源点，所以每个点都会多松弛一次，判断负环需要 n + 1
                if(!vis[v]) q.push(v), vis[v] = 1;
            }
        }
    }
    return false;
}

void solve(){
    cin >> n >> m;
    memset(h, -1, sizeof h);
    for(int i = 1; i <= m; i++){
        int a, b; double c;
        cin >> a >> b >> c;
        add(a, b, c);
    }
    for(int i = 1; i <= n; i++) add(0, i, 0);
    double l = -1e7, r = 1e7;
    while(r - l > 1e-10){
        double mid = (l + r) / 2;
        if(check(mid)) r = mid;
        else l = mid;
    }
    cout << fixed << setprecision(8) << r << endl;
}

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int T = 1;
    //cin >> T;
    while(T--) solve();
    return 0;
}
```

## [P2868 [USACO07DEC] Sightseeing Cows G](https://www.luogu.com.cn/problem/P2868)(SPFA + 分数规划)

边权 $w_i$，点权 $f_i$，求一个环 $C$，使得 $\displaystyle \frac{\sum_{i \in C} f_i}{\sum_{i \in C} w_i}$ 最大。

$\displaystyle \frac{\sum_{i \in C} f_i}{\sum_{i \in C} w_i} \leq x \Longrightarrow \sum (f_{u_i} - x * w_i) \leq 0 \Longrightarrow \sum (x * w_i - f_{u_i}) \geq 0$
$(u 为边 i 的出点，当然，因为是环，用入点也可)$

因此，二分一个答案 $x$，将 $x * w_i - f_{u_i}$ 作为边权，判断图上是否存在负环，若存在负环，则 $x$ 应当增大，取 $l = mid$；否则，$x$ 可尝试变小，取 $r = mid$。

时间复杂度：$\mathcal O(nm * log(1e7))$

```cpp
#include <bits/stdc++.h>
using namespace std;
#define endl '\n'
#define int long long
const int N = 1e3 + 10, M = 6e3 + 10, inf = 0x3f3f3f3f, INF = 1e18;

int n, m;
int h[N], e[M], ne[M], w[M], idx, f[N];
double dist[N];
int cnt[N], vis[N];

void add(int a, int b, int c){
    w[idx] = c;
    e[idx] = b;
    ne[idx] = h[a];
    h[a] = idx++;
}

bool check(double x){
    for(int i = 1; i <= n; i++) dist[i] = inf, cnt[i] = 0, vis[i] = 0;
    queue<int> q;
    q.push(0);
    vis[0] = 1;
    while(!q.empty()){
        int u = q.front(); q.pop();
        vis[u] = 0;
        for(int i = h[u]; ~i; i = ne[i]){
            int v = e[i];
            if(dist[v] > dist[u] + x * w[i] - f[u]){
                dist[v] = dist[u] + x * w[i] - f[u];
                cnt[v] = cnt[u] + 1;
                if(cnt[v] >= n + 1) return true; // 存在负环
                if(!vis[v]) q.push(v), vis[v] = 1;
            }
        }
    }
    return false;
}

void solve(){
    cin >> n >> m;
    memset(h, -1, sizeof h);
    for(int i = 1; i <= n; i++) cin >> f[i], add(0, i, 0);
    for(int i = 1; i <= m; i++){
        int a, b, c; cin >> a >> b >> c;
        add(a, b, c);
    }
    double l = 0, r = 1e3;
    while(r - l > 1e-4){
        double mid = (l + r) / 2;
        if(check(mid)) l = mid; // 存在负环
        else r = mid;
    }
    cout << fixed << setprecision(2) << r << endl;
}

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int T = 1;
    // cin >> T;
    for(int i = 1; i <= T; i++) solve();
    return 0;
}
```

## [CF489E Hiking](https://codeforces.com/contest/489/problem/E)(线性DP + 分数规划)

时间复杂度：$\mathcal O(n^2 * log(1e13))$

```cpp
#include <bits/stdc++.h>
using namespace std;
#define endl '\n'
#define int long long
const int N = 1e3 + 10, inf = 0x3f3f3f3f;

int n, nl;
int p[N], b[N], pre[N];
double dp[N];
// dp[i]: 从起点0 走到第 i 号休息点，修改后总代价最小值

bool check(double x){
    for(int i = 1; i <= n; i++){
        dp[i] = inf;
        for(int j = 0; j < i; j++){
            double tmp = dp[j] + sqrt(abs(p[i] - p[j] - nl)) - x * b[i];
            if(dp[i] > tmp){
                dp[i] = tmp;
                pre[i] = j;
            }
        }
    }
    return dp[n] >= 0;
}

void dfs(int u){
    if(pre[u]) dfs(pre[u]);
    cout << u << " \n"[u == n];
}

void solve(){
    cin >> n >> nl;
    for(int i = 1; i <= n; i++) cin >> p[i] >> b[i];
    double l = 0, r = 1e6;
    while(r - l > 1e-7){
        double mid = (l + r) / 2;
        if(check(mid)) l = mid; // 若 dp[n] >= 0, 则说明 mid 可以尝试取更大
        else r = mid;
    }
    dfs(n);
}

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int T = 1;
    // cin >> T;
    for(int i = 1; i <= T; i++) solve();
    return 0;
}
```
